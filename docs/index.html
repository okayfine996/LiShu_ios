常见问题

打开应用后，点击首页的「记一笔」按钮或底部标签栏的「记录」页面，选择联系人、填写金额、选择事件和方向（送/收），即可快速完成一笔记录。您也可以通过 OCR 拍照功能批量导入纸质礼簿。
Pro 会员解锁以下功能：无限联系人与记录数量（免费版各限 20 条）、完整统计分析（收支趋势、圈层分析、热力图、排行榜）、数据导出（CSV/JSON）、iCloud 多设备同步，以及每月无限次 OCR 识别（免费版每月 3 次）。提供月度订阅（¥7/月）、年度订阅（¥59/年，含 1 周免费试用）和终身买断（¥99）三种方案。
您可以随时前往 iPhone 的「设置 → Apple ID → 订阅」中管理或取消订阅。取消后，当前已付费周期仍可继续使用全部 Pro 功能，到期后将不再续费。所有购买和退款均通过 Apple 处理，如需退款请联系 Apple 客服。
您的所有数据默认存储在设备本地，不会上传至任何第三方服务器。开启 iCloud 同步后，数据通过 Apple iCloud 加密传输和存储，仅您本人可访问。我们不使用任何第三方分析或广告追踪工具，不收集、不出售您的个人信息。
Pro 会员可以在「设置 → 数据管理」中选择导出格式（CSV 或 JSON），导出的文件包含所有联系人、事件和记录信息，可通过系统分享功能保存到文件、发送邮件或使用其他应用打开。
您可以通过应用内「设置 → 关于 → 意见反馈」直接发送邮件，也可以直接发送邮件至 support@finefine.com，我们会尽快回复。
